# NEXUS OS Settings Subsystem

The Settings subsystem integrates deeply with KDE Plasma 6's KConfigModules (KCM) and adds specialized developer and AI control panels:
- **AI Models & Accelerators**: GPU/VRAM allocation, Ollama model manager, and cloud provider API keys.
- **Developer Environments**: `mise` toolchains, Podman container registries, and default IDE preferences.
- **Spotlight & Privacy**: Configurable indexing roots, file exclusions, and command permission guards.
- **Aether Appearance**: Accent color picker, light/dark scheduling, and window corner radius adjustments.
